## About Me

I'm a senior full-stack web developer with a strong front-end focus. I've worked on SaaS platforms, large-scale management systems, e-commerce solutions, and content platforms, and I like owning a feature end to end: from the data and API layer to a pixel-accurate, responsive, accessible interface.

I care about the details that separate good interfaces from great ones: layout fundamentals, performance, motion, and accessibility. I also enjoy understanding the platform deeply rather than only using abstractions, which is why I regularly study specs, browser internals, and system design mechanics from first principles.
